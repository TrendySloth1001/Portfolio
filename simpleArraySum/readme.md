# simpleArraySum

This project contains a TypeScript implementation of the "Simple Array Sum" problem.

## Problem

Given an array of integers, find the sum of its elements.

## Usage

The main logic is implemented in `code.ts`. The function signature is:

```typescript
function simpleArraySum(ar: number[]): number
```

It takes an array of numbers and returns their sum.

## Example

Input:
```
5
1 2 3 4 5
```

Output:
```
15
```

## How it works

- Reads input from stdin.
- Parses the array.
- Calls `simpleArraySum` to compute the sum.
- Writes the result to the output file.

## Running

To run the code, use Node.js:

```bash
node code.ts
```

Make sure to set the `OUTPUT_PATH` environment variable to specify the output file.
